> 上傳 Excel → 自動依「型號、尺寸」產生每張床的標籤 → 直接送 GoDEX G500+ 標籤機列印。
> 不需要再開 GoLabel 一張一張改文字。

## 1. 這個工具能做什麼

- 用一份固定格式的 Excel，一次產生整批床墊標籤。
- 每個型號的成分、布料、品牌 Logo 只要在 Excel 設定一次，之後只填「型號、尺寸、數量」。
- 列印前可以在網頁上**預覽每一張標籤**，預覽的樣子就是印出來的樣子。
- Excel 有填錯的地方（型號打錯、數量空白……）會**逐列列出錯誤**，填對的列照樣可以印。
- 列印到一半失敗（沒紙、斷線）會停下來，排除後可以**從失敗處繼續**，不會重複印。
- 每次列印都會留下**列印紀錄**。

標籤上印的內容（由上到下）：

```
[品牌 Logo]
型號:懶骨窩
成分:高碳鋼袋裝獨立筒
     天然乳膠層
     ……（成分一項一行）
     Polyester 66%  Lyocell(天絲) 34%   ← 布料
尺寸:152 x 188 cm
製造廠商:快樂床業有限公司
廠商地址:新北市新店區安康路二段3-2號
統一編號:34609285
服務專線:(02)2211-7010
製造地:台灣
```

文字太多放不下時，程式會**自動縮小字體**讓內容塞進標籤。

## 2. 系統需求

| 項目 | 需求 |
|---|---|
| 電腦 | Windows 10 / 11，或 Mac（擇一台當「列印主機」） |
| 軟體 | Python 3（免費，安裝方式見下方） |
| 標籤機 | GoDEX G500+（203 dpi），**網路線**連接，或 **USB** 接在列印主機上（USB 只支援 Windows，需先裝好 GoDEX 驅動程式） |
| 網路 | 使用網路線時，列印主機與標籤機必須在**同一個網路**內 |
| 瀏覽器 | Chrome、Edge、Safari 皆可 |
| Excel | 可存成 `.xlsx` 的任何版本 |

> 💡 只有「列印主機」需要安裝。辦公室其他電腦用瀏覽器打開網址就能使用，不用安裝任何東西。

## 3. 安裝與啟動

### 3-1. Windows（第一次）

1. 到 <https://www.python.org/downloads/> 下載並安裝 Python 3。
   ⚠️ 安裝畫面最下方務必勾選 **「Add Python to PATH」**，再按 Install Now。
2. 把整個 `AutoLogo` 資料夾複製到電腦上（例如桌面）。
3. 雙擊資料夾內的 **`start.bat`**。
   - 第一次會自動下載安裝需要的套件，約 1～2 分鐘，請等待。
   - 若跳出 **Windows 防火牆** 詢問，請按 **「允許存取」**（勾選「私人網路」），否則其他電腦連不進來。
4. 瀏覽器會自動打開 `http://localhost:8000`，看到「床墊標籤列印」頁面就完成了。

### 3-2. Mac（第一次）

1. Mac 通常已內建 Python 3。若沒有，到 <https://www.python.org/downloads/> 安裝。
2. 雙擊 **`start.command`**。
   - 若出現「無法打開，因為來自未識別的開發者」：在檔案上 **按右鍵 → 打開 → 打開**。
3. 瀏覽器會自動打開 `http://localhost:8000`。

### 3-3. 之後每天使用

- 雙擊 `start.bat`（Windows）或 `start.command`（Mac）即可，不會再重新安裝。
- 啟動後會出現一個**黑色視窗**（Mac 為「終端機」視窗），上面會顯示：

  ```
  標籤列印工具已啟動：
    本機：http://localhost:8000
    其他電腦：http://192.168.1.23:8000
  關閉此視窗即停止。
  ```

- **使用期間不要關掉黑色視窗**；關掉就等於關閉程式。

### 3-4. 從其他電腦使用

在同一網路的任何電腦，打開瀏覽器，輸入黑色視窗上「其他電腦」那一行的網址（例如 `http://192.168.1.23:8000`）。
建議把這個網址加入瀏覽器書籤。

> ⚠️ 列印主機必須開著、而且黑色視窗要在執行中，其他電腦才能使用。

## 4. Excel 填寫方式

在「列印」頁按 **「下載 Excel 範本」** 取得 `標籤範本.xlsx`，裡面有三個工作表：

### 4-1. 工作表「型號資料」（每個型號一列，設定一次即可）

| 型號 | 品牌Logo | 成分 | 布料 |
|---|---|---|---|
| 懶骨窩 | HO-ZZZ | 高碳鋼袋裝獨立筒<br>天然乳膠層<br>高密度釋壓棉<br>高密度支撐泡棉<br>封邊泡棉床緣底面強化<br>天絲緹花床墊專用布 | Polyester 66%  Lyocell(天絲) 34% |

| 欄位 | 說明 | 必填 |
|---|---|---|
| 型號 | 印在標籤上的型號名稱。**不可重複**。 | ✅ |
| 品牌Logo | Logo 圖檔名稱（不含副檔名），例如 `HO-ZZZ`。圖檔需先在「設定」頁上傳，見[第 7 節](#7-品牌-logo-管理)。 | ✅ |
| 成分 | **一項一行**。在同一格內換行：Windows 按 `Alt + Enter`，Mac 按 `Option + Enter`（或 `Control + Option + Enter`）。 | ✅ |
| 布料 | 印在成分最後一行，可空白。 | |

### 4-2. 工作表「訂單」（每次要印的內容）

| 型號 | 寬(cm) | 長(cm) | 數量 | 備註 |
|---|---|---|---|---|
| 懶骨窩 | 152 | 188 | 3 | |
| 懶骨窩 | 182 | 188 | 2 | 雙人加大 |

| 欄位 | 說明 | 必填 |
|---|---|---|
| 型號 | 必須與「型號資料」中的型號**完全相同**（全形半形、文字中間的空格都要一致；前後多餘空格會自動忽略）。 | ✅ |
| 寬(cm) / 長(cm) | 填數字即可，單位公分。可有小數，例如 `91.5`。 | ✅ |
| 數量 | 這個規格要印幾張，必須是**正整數**。 | ✅ |
| 備註 | 給自己看的，**不會印出來**。 | |

### 4-3. 工作表「說明」

範本內附的填寫說明，可保留或刪除，程式不會讀取。

### 4-4. 填寫規則（重要）

- ❌ **不要修改工作表名稱**（「型號資料」、「訂單」）。
- ❌ **不要修改第 1 列的欄位名稱**。欄位的左右順序可以調整，也可以在最右邊加自己的欄位，程式會忽略。
- ✅ 中間有空白列沒關係，會自動略過。
- ✅ 檔案請存成 `.xlsx`。
- ✅ 「型號資料」可以一直累積所有型號；每次只要更新「訂單」就好。

> 💡 建議做法：保留一份「主檔」Excel 維護所有型號，每次出貨時另存新檔、只改「訂單」工作表。

## 5. 日常列印流程

### 步驟 1：上傳 Excel
在「列印」頁，把 Excel 檔**拖曳到虛線框**中，或點虛線框選擇檔案。

### 步驟 2：檢查錯誤
如果 Excel 有問題，上方會出現**黃色框**列出所有錯誤，例如：

```
訂單第 5 列：寬「abc」不是正數；數量「」不是正整數
訂單第 8 列：型號「懶骨窩2」不在型號資料中
型號資料第 3 列（新品）：找不到 logo 圖檔「ABC」，請到設定上傳
```

- 有錯的列**不會出現在列印清單**，其他正確的列照樣可以印。
- 要印有錯的列：修正 Excel → 存檔 → **重新上傳**。

### 步驟 3：預覽與勾選
- 表格會列出每一筆：Excel 列號、型號、尺寸、張數、備註、預覽圖。
- **點預覽小圖**可以放大檢查。
- 用最左邊的勾選框選擇要印的列（預設全選）。上方會顯示「已選 X 筆、合計 Y 張」。

### 步驟 4：列印
1. 按 **「列印選取」** → 確認張數 → 按「確定」。
2. 每一筆的「狀態」欄會依序顯示「列印中…」→「✓ 已送出」。
3. 全部完成會顯示「完成：N 筆已送出」。

### 步驟 5：列印失敗時
- 遇到錯誤（例如標籤機沒紙、斷線）會**立刻停止**，該列顯示紅色「失敗」，上方顯示原因。
- 程式在每一張**送出前、送出後都會詢問標籤機狀態**。標籤機回報缺紙、碳帶用完、上蓋沒蓋好等錯誤時，會直接顯示中文原因與建議。
- 排除問題後按 **「從失敗處繼續」**，會從失敗的那一筆接著印，**已印好的不會重印**。
- 原因看不懂、或印出來怪怪的：按旁邊的 **「複製診斷資訊」**，見[第 9 節](#9-診斷與回報問題)。

> ⚠️ 有些標籤機不回應狀態詢問。這時「已送出」只代表資料已傳到標籤機，請以實際出紙為準。

### 查看列印紀錄
點上方 **「列印紀錄」** 分頁，可看最近 200 筆（時間、型號、尺寸、張數、成功/失敗、訊息）。
完整紀錄存在程式資料夾的 `print_log.csv`，可直接用 Excel 開啟。

## 6. 設定頁說明

點上方 **「設定」** 分頁。修改後記得按最下方 **「儲存設定」**。右側「範例預覽」會即時顯示調整後的標籤樣子（灰框為標籤紙邊緣）。

### 6-1. 印表機

| 設定 | 預設值 | 說明 |
|---|---|---|
| 連線方式 | 網路 | **網路**：標籤機接網路線。**USB**：標籤機用 USB 線接在這台 Windows 電腦上。 |
| USB 印表機 | （自動帶入） | 選 USB 時才出現。Windows「印表機與掃描器」裡的名稱，例如 `Godex G500`；名稱含 GoDEX 的印表機會自動帶入。 |
| IP 位址 | 192.168.1.1 | 選網路時才出現。標籤機的網路位址，**第一次一定要確認**（見第 8 節）。 |
| 連接埠 | 9100 | 選網路時才出現。GoDEX 網路列印埠，一般不用改。 |
| 濃度 | 10 | 0～19，數字越大越黑。太淡就調高、糊掉就調低。 |
| 速度 | 4 | 數字越大越快；字不清楚時可調慢。 |
| 解析度 | 203 | G500+ 為 203 dpi，不要改。若日後換 300 dpi 機型才改成 300。 |
| 列印方式 | 維持印表機目前設定 | **熱轉印**：有裝碳帶時選。**熱感**：沒有碳帶、用感熱紙時選。選錯會印出全白或報錯。不確定時看標籤機裡有沒有一捲黑色碳帶。 |
| 送圖方式 | Q 指令 | 標籤圖送給標籤機的方式。**Q 指令**：GoDEX 官方 SDK 用的方式（預設）。**BMP 下載**：先把圖存進標籤機再列印，GoLabel 類似的方式。用「綜合測試」看哪一種印得出來，就選那一種（見 9-2）。 |
| 黑白反相 | 不勾 | 印出來黑白顛倒（整張變黑）時勾選。 |
| 測試模式 | 不勾 | 勾選後**不會真的列印**，而是把列印資料存成檔案到 `output` 資料夾。測試 Excel 時很方便，**正式列印前記得取消勾選**。 |

按鈕：
- **連線測試**：檢查能不能連上標籤機，並顯示標籤機目前狀態（例如「00：正常待機」、「01：缺紙或卡紙」）。
  > 💡 USB 連線也能讀標籤機狀態碼：程式會直接開啟 USB 裝置查詢（Windows 列印佇列本身只能單向送資料）。若顯示「印表機沒有回傳狀態」，代表這台不是 USB 直連（例如網路分享的印表機），請以實際出紙與 STATUS 燈為準。
- **測試列印 1 張**：用範例資料（懶骨窩 152×188）印一張。

### 6-2. 標籤紙（單位：mm）

| 設定 | 預設值 | 說明 |
|---|---|---|
| 寬 / 高 | 100 / 150 | 單張標籤紙的寬、高。 |
| 間距 (gap) | 3 | 兩張標籤之間的空隙。**整捲連續沒有分隔的紙填 0**，標籤機就不會找間距（找不到間距會亮紅燈、回報「缺紙或卡紙」）；此時「高」就是每張要印多長。 |
| 左右偏移 | 0 | 整張內容往右移（正數）或往左移（負數）。 |
| 上下偏移 | 0 | 整張內容往下移（正數）或往上移（負數）。 |
| 邊界 | 4 | 內容離標籤邊緣的距離。 |
| Logo 上方留白 (mm) | 0 | 在邊界之外，Logo 上方再多留的空白。調大會讓 Logo 和下面的文字一起往下移。 |
| Logo 高度比例 | 0.32 | Logo 佔標籤高度的比例。0.32 = 約三分之一。 |
| 最大字高 | 4.5 | 文字最大高度（mm）。內容多時會自動縮小。 |

### 6-3. 公司資料

製造廠商、廠商地址、統一編號、服務專線、製造地。**每張標籤都相同**，在這裡改一次即可，不用寫在 Excel。

### 6-4. 字型

- **空白（建議）**：自動使用電腦內的中文字型。Windows 使用「微軟正黑體」，筆畫較粗，在標籤機上印起來比細明體清楚。
- 想指定字型：填入字型檔完整路徑，例如 `C:\Windows\Fonts\mingliu.ttc`（細明體）。
- 或者把 `.ttf` / `.otf` / `.ttc` 字型檔放進程式的 `fonts` 資料夾，會優先使用。
- 「字型編號」只有 `.ttc` 字型集才需要，一般填 0。

## 7. 品牌 Logo 管理

在「設定」頁最下方「品牌 Logo」區塊：

1. 「品牌名稱」輸入名稱，例如 `HO-ZZZ`。
2. 選擇圖檔（PNG、JPG、BMP）。
3. 按 **「上傳」**。
4. 在 Excel「型號資料」的「品牌Logo」欄填**一模一樣的名稱**。

注意事項：
- 名稱不可包含 `\ / : * ? " < > |`。
- 上傳相同名稱會**取代**舊圖。
- 標籤機只能印黑白，彩色或灰階 Logo 會被轉成黑白。請盡量使用**黑白、高對比、背景透明或白色**的圖檔，效果最好。
- Logo 會自動縮放置中，不需要先調整大小。

## 8. 第一次安裝：實機測試步驟

> 這一節給**負責安裝的人**。完成一次後，日常使用者不用再做。

### 8-1. 事前準備
- [ ] 列印主機已安裝 Python 3，並能用 `start.bat` 開啟工具（第 3 節）。
- [ ] 準備一把尺。
- [ ] 標籤機已裝好標籤紙（與碳帶，若使用熱轉印），並接上網路線。

### 8-2. 確認三件事

| 項目 | 怎麼查 |
|---|---|
| **標籤機 IP** | 在 GoLabel 的印表機設定 / 網路設定查看，或依 G500+ 說明書列印自我測試（設定）頁。注意：`192.168.1.1` 通常是**路由器**，不一定是標籤機。 |
| **標籤紙尺寸** | 用尺量一張標籤的寬、高，以及兩張之間的間距（mm）。也可以參考 GoLabel 的標籤設定。 |
| **同一網路** | 列印主機與標籤機的 IP 前三段通常相同，例如都是 `192.168.1.x`。 |

裝好標籤紙後，請依 G500+ 說明書執行一次**紙張校正**，讓標籤機知道每張標籤從哪裡開始。

### 8-3. 用「校正」分頁一步步調整（建議）

換新標籤機、換不同的紙，或印出來被切掉、全白時，點上方 **「校正」** 分頁，從 ① 做到 ⑤：

| 步驟 | 做什麼 | 看什麼 |
|---|---|---|
| ① 連線與狀態 | 按「檢查印表機狀態」 | 顯示「00：正常待機」才往下做；紅燈就先按「清除錯誤」 |
| ② 紙張與列印方式 | 選「間距紙」或「連續紙」、熱感或熱轉印，按「套用並寫入印表機」 | 狀態回到 00。連續紙選成間距紙會亮紅燈（01 缺紙或卡紙）；沒碳帶選成熱轉印會全白 |
| ③ 寬度與位置 | 按「印尺規」，把紙上**最左、最右看得到的數字**填進去 → 「計算寬度並套用」→「用新寬度印驗證尺規」 | 驗證尺規應從紙的左邊緣 0 開始；不是的話把左邊緣的數字填進去再套用 |
| ④ 送圖方式 | 按「印綜合測試（3 張）」，依結果選 Q 指令或 BMP | 第 3 張有測試圖 → Q 指令；只有第 2 張有 → BMP；黑白相反 → 勾選 |
| ⑤ 範例標籤 | 按「印範例標籤」 | 跟右邊預覽一樣就完成；太淡、太黑調濃度 |

> 尺規是照「印字頭寬度」（G500 為 104mm）整條印出，每 5mm 一條刻度、每 10mm 一個數字。紙比印字頭窄時，只看得到中間一段，左右兩端的數字就是紙的位置。

### 8-4. 依序測試

**A. 連線測試**
1. 設定頁填入 IP，連接埠保持 `9100`。
2. 按 **「連線測試」**。
   - ✅ 顯示「已連上」→ 進行 B。
   - ❌ 失敗 → 檢查 IP、網路線、是否同一網路。

**B. 印一張測試標籤**
1. 填入標籤紙寬、高、間距。
2. 確認 **「測試模式」沒有勾選**。
3. 按 **「測試列印 1 張」**，依結果調整：

| 印出結果 | 處理方式 |
|---|---|
| ✅ 內容正確 | 完成，進行 C |
| 黑白顛倒（整張幾乎全黑） | 勾選「黑白反相」，再印一次 |
| 印出 `Q0,0,100…` 之類的文字或亂碼 | 標籤機沒有用 EZPL 指令模式。請在標籤機或 GoDEX 工具中確認指令語言為 EZPL |
| 內容偏移、某一邊被切掉 | 調整「左右偏移 / 上下偏移」（可填負數） |
| 一張內容跨到兩張紙，或越印越偏 | 寬、高、間距不正確 → 重新量測，並重新做紙張校正 |
| 太淡 / 太黑 | 調整「濃度」，每次加減 2～3 |
| 字糊、不清楚 | 濃度稍微調高，或「速度」調慢 |
| 出紙但全白、STATUS 燈變紅 | 見第 10 節「印出全白」那一列 |
| 顯示「已送出」但完全沒出紙 | 到「診斷」分頁產生報告，見 8-5 |

**C. 實際批次測試**
1. 下載 Excel 範本，「訂單」只留一列、數量填 **2**。
2. 上傳、列印。
3. 確認**剛好出 2 張**，尺寸文字正確。

**D. 失敗續印測試**
1. 準備 2～3 列的訂單，開始列印。
2. 列印途中打開標籤機上蓋或拔掉網路線。
3. 工具應停止並顯示錯誤；排除後按「從失敗處繼續」，確認可以接著印完。

**E. 其他電腦連線（選擇性）**
在另一台電腦開啟黑色視窗上「其他電腦」的網址，確認可以使用。

### 8-5. 測試不順利時，請提供以下資料給技術人員
1. **診斷報告**：到「診斷」分頁按「產生診斷報告」→「複製報告」，整段貼過去（見第 9 節）。
2. **綜合測試照片**：按「綜合測試（3 張）」，3 張放在一起拍一張照片。
3. **自我測試頁照片**：按「列印自我測試頁」並拍照。
4. 標籤機正面兩顆指示燈（READY、STATUS）的顏色。

## 9. 診斷與回報問題

> 這一節給**現場操作人員**。負責的人不在現場時，靠這份報告就能判斷問題出在哪裡。

### 9-1. 產生並複製診斷報告
1. 點上方 **「診斷」** 分頁（或列印失敗時，按進度列旁的 **「複製診斷資訊」**，會自動跳過來）。
2. 按 **「產生診斷報告」**，等幾秒，下方文字框會出現報告。
3. 按 **「複製報告」**，看到「已複製，可直接貼給 AI」就完成了。
   - 若顯示「無法自動複製」：文字已經全選，直接按 `Ctrl + C`（Mac 按 `⌘ + C`）。
4. 把報告**整段**貼到 LINE、Email 或 AI 對話框，**再附上出紙照片**。

報告內容包含：
| 區塊 | 用途 |
|---|---|
| 程式檔版本 | 確認這台電腦的程式有沒有更新到最新版 |
| 印表機 | 連線結果、標籤機回報的狀態碼與中文說明 |
| 自動檢查 | 程式自動找出的可疑設定，以及建議處理方式 |
| 最近一次送出的指令 | 實際送給標籤機的指令內容（圖片資料只列摘要） |
| 標籤圖 | 標籤圖的尺寸、使用的字型 |
| 設定 | 所有設定值 |
| 最近 10 筆列印紀錄 | 成功/失敗與訊息 |

> 報告裡沒有密碼或個人資料，可以放心貼給 AI 判讀。

### 9-2. 測試與遠端控制按鈕
「診斷」分頁下方的按鈕，可以**從電腦直接操作標籤機**，不用到機台旁邊按：

| 按鈕 | 作用 | 什麼時候用 |
|---|---|---|
| **綜合測試（3 張）** | 連續印 3 張測試標籤，一張照片就能判斷問題在哪一層（見下表） | 印出全白、或第一次安裝時 |
| 基本測試（不含圖片） | 印一張只有外框和英文字 `GODEX TEST OK` 的標籤 | 只想確認標籤機能不能印字 |
| 列印自我測試頁 | 標籤機印出自己的設定頁（列印方式、紙張長度、感測器數值、韌體版本） | 回報問題時，拍照一起附上 |
| 清除錯誤 | 等同按標籤機的取消鍵，清除錯誤狀態 | STATUS 紅燈、排除問題之後 |
| 紙張自動偵測 | 標籤機自動量測標籤長度與間距（會送出幾張空白標籤） | 換新一捲標籤紙後、出現「缺紙或卡紙」但紙其實有裝好時 |
| 送紙一次 | 等同按一下 FEED 鍵 | 確認標籤機有反應 |

**綜合測試怎麼看：**

3 張標籤都有外框和英文字；第 2、3 張在一條橫線**下方**還有一個測試圖：**左半全黑、右半空心框、右上角一條黑槓**。

| 第 1 張（只有文字） | 第 2 張（BMP） | 第 3 張（Q） | 問題在哪裡 / 怎麼做 |
|---|---|---|---|
| 全白 | 全白 | 全白 | 標籤機、紙張或列印方式有問題：看標籤機燈號與診斷報告的「自動檢查」，確認「列印方式」與碳帶相符 |
| 有字 | 有圖 | 有圖 | 兩種方式都正常，維持預設「Q 指令」 |
| 有字 | 有圖 | 沒有圖 | 設定頁「送圖方式」改成「BMP 下載」 |
| 有字 | 沒有圖 | 有圖 | 維持「Q 指令」 |
| 有字 | 測試圖黑白相反（左白右黑） | 同左 | 勾選「黑白反相」 |
| 有字 | 測試圖不在橫線正下方、或上下顛倒 | 同左 | 拍照回報 |

> 請把 3 張**放在一起拍一張照片**，連同診斷報告一起回報。

### 9-3. 標籤機狀態碼對照
| 狀態碼 | 意思 | 處理方式 |
|---|---|---|
| 00 | 正常待機 | — |
| 01 / 02 | 缺紙或卡紙 | 確認標籤紙裝好；有裝好的話按「紙張自動偵測」 |
| 03 | 碳帶用完 | 沒裝碳帶 → 設定頁「列印方式」改成「熱感」；有裝 → 檢查碳帶是否用完或裝反 |
| 04 | 上蓋或印字頭沒蓋好 | 蓋好上蓋、壓下印字頭 |
| 06 | 記憶體已滿 | 使用「BMP 下載」時可能發生：按「清除錯誤」再試，或改回「Q 指令」 |
| 09 | 指令語法錯誤 | 按「綜合測試」，把照片與診斷報告傳給技術人員 |
| 20 | 暫停中 | 按 FEED 鍵或「清除錯誤」 |
| 沒有回應 | 這台標籤機不回報狀態 | 請現場看 STATUS 燈顏色並拍照 |

## 10. 常見問題排除

| 問題 | 原因與解決方式 |
|---|---|
| 雙擊 `start.bat` 顯示「請先安裝 Python 3」 | 尚未安裝 Python，或安裝時沒勾「Add Python to PATH」。重新安裝 Python 並勾選該選項。 |
| 黑色視窗出現錯誤訊息後停住 | 視窗會停在錯誤畫面（按任意鍵才關閉）。請拍照或截圖錯誤內容給系統管理人員。 |
| 第一次安裝套件失敗 | 確認電腦可以上網，再重新雙擊 `start.bat`。若仍失敗，刪除 `.venv` 資料夾後再試一次。 |
| 瀏覽器顯示「無法連上這個網站」 | 黑色視窗被關掉了，重新雙擊 `start.bat`。 |
| 其他電腦打不開網址 | ① 列印主機沒開或黑色視窗沒在執行　② Windows 防火牆擋住：到「Windows 安全性 → 防火牆 → 允許應用程式通過防火牆」允許 Python　③ 不在同一個網路。 |
| 列印時顯示「無法連線印表機」 | 標籤機沒開機、網路線鬆脫、IP 錯誤，或標籤機 IP 被路由器改掉了。到設定頁按「連線測試」確認。建議請網管把標籤機設為**固定 IP**。 |
| USB：顯示「找不到 Windows 印表機」 | 設定頁「USB 印表機」名稱與 Windows 裡的不一樣，從下拉選單重新選擇。清單裡沒有 GoDEX → 先安裝 GoDEX 驅動程式。 |
| USB：顯示「在 Windows 列印佇列等了 30 秒仍未送到印表機」 | USB 線鬆脫或標籤機沒開機。程式已自動取消這張，不會之後才補印；接好後按「從失敗處繼續」即可。 |
| 列印時顯示「找不到這批資料，請重新上傳 Excel」 | 程式重新啟動過，上傳的資料已清除。重新上傳 Excel 即可。 |
| 上傳後顯示「找不到工作表『型號資料』」 | 工作表名稱被改了。請改回「型號資料」與「訂單」。 |
| 上傳後顯示「第 1 列缺少欄位」 | 欄位名稱被改了（例如「寬(cm)」的括號打成全形「（）」）。請從範本複製正確的欄位名稱。 |
| 型號明明有填，卻說「不在型號資料中」 | 兩邊的型號文字不完全一樣（文字中間多一個空格、全形/半形不同）。建議用複製貼上。 |
| 某型號的所有訂單都被標為「型號資料有誤」 | 該型號在「型號資料」工作表本身有錯（例如 Logo 找不到、成分空白），先修正上方列出的型號資料錯誤。 |
| 顯示「找不到 logo 圖檔」 | 品牌Logo 名稱與上傳的名稱不一致，或還沒上傳。到設定頁的 Logo 區確認名稱。 |
| 按了列印但沒出紙，狀態也顯示「已寫入 output/…」 | 「測試模式」被勾選了。到設定頁取消勾選並儲存。 |
| **印出全白**、標籤機 STATUS 燈變紅 | 依序做：① 「診斷」按「清除錯誤」（或按 FEED 鍵）讓紅燈消失　② 按「紙張自動偵測」　③ 確認設定頁「列印方式」與有沒有裝碳帶相符　④ 按「綜合測試（3 張）」，依 9-2 的表判斷　⑤ 仍有問題 → 按「列印自我測試頁」，把所有照片和診斷報告一起回報（第 9 節）。 |
| 列印失敗訊息寫「印表機回報錯誤 ○○」 | 依訊息後面的「建議」處理，狀態碼對照見 9-3。 |
| 字太小 | 標籤內容太多被自動縮小。可減少成分行數、調小「Logo 高度比例」或「邊界」、或改用較大的標籤紙。 |
| 中文變成方塊 □□□ | 字型找不到中文字。到設定頁「字型」填入中文字型路徑，或放字型檔到 `fonts` 資料夾。 |

## 12. 備份與更新

### 需要定期備份的檔案
| 檔案 | 內容 |
|---|---|
| `config.json` | 印表機 IP、標籤尺寸、公司資料等所有設定 |
| `logos/` 資料夾 | 所有品牌 Logo |
| `print_log.csv` | 列印紀錄 |
| 你的 Excel 主檔 | 所有型號資料 |

### 換電腦
1. 把整個 `AutoLogo` 資料夾複製到新電腦。
2. 新電腦安裝 Python 3。
3. 雙擊 `start.bat`，會自動重新安裝套件。設定與 Logo 都會保留。

**免安裝版（新電腦不用裝 Python）**：在原本的電腦雙擊 `build.bat`，會產生 `dist\AutoLogo.zip`。把 zip 複製到新電腦（Windows 10/11 64 位元）、解壓縮，雙擊裡面的 `AutoLogo.exe` 即可，瀏覽器會自動開啟。`config.json`、`logos/`、`print_log.csv` 都在 `AutoLogo.exe` 旁邊，備份方式同上。Windows 若跳出「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。

### 更新程式（從雲端自動更新）
程式會在開啟時自動檢查 GitHub 上有沒有新版本。有新版本時，右上角會出現黃色的「有新版本，按此更新」。

1. 按右上角的黃色提示，或到「診斷」分頁的「程式更新」按「檢查更新」。
2. 確認更新內容後按「立即更新」。
3. 程式會跳出「AutoLogo 更新」視窗、自動關閉再重新開啟，約 1 分鐘。網頁會自動重新整理，右上角會顯示新的版本號。

- 更新會**保留** `config.json`、`logos/`、`print_log.csv`、`output/`、`fonts/`。
- 列印中不能更新，請等列印完成。
- 電腦要能連上網際網路（github.com）。
- `start.bat` 版和免安裝的 `AutoLogo.exe` 版都可以自動更新。Mac 版不支援，請手動覆蓋程式檔。
- 更新失敗時，「AutoLogo 更新」視窗會顯示原因，舊版程式不受影響。請關掉所有 AutoLogo 視窗，重新開啟後再試一次。

### 發布新版（給維護程式的人）
在 Mac 的「終端機」進入程式資料夾，執行：

```
./release.sh 1.1.0 "這次更新的內容"
```

版本號要比上一版大。GitHub 約 5 分鐘後會打包好 `AutoLogo.exe` 並發布到 Releases 頁面，之後各電腦按「檢查更新」就會看到。打包進度可以在 GitHub 儲存庫的 **Actions** 頁面查看。
