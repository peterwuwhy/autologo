① 連線與狀態

目前連線：　（要換印表機或連線方式，請先到「設定」頁修改並儲存）

② 紙張與列印方式

亮紅燈、狀態「01 缺紙或卡紙」但紙其實有裝好 → 通常是紙張類型選錯（連續紙選成間距紙）。 沒有裝黑色碳帶就選「熱感」，選錯會出紙但全白。

③ 寬度與位置

先印尺規，看印在紙上的刻度數字（單位 mm），程式會算出紙寬並讓內容對準紙張。

驗證（建議）：用算好的寬度再印一次尺規，紙的左邊緣應該剛好從 0 開始。 不是從 0 開始，就填左邊緣看到的數字，內容會往右移這麼多。

④ 送圖方式

印 3 張測試：1 只有文字、2 用 BMP 方式的測試圖、3 用 Q 指令的測試圖（左半黑、右半空心框）。

⑤ 範例標籤

太淡 → 濃度調高 2～3；糊掉 → 調低；字不清楚 → 速度調慢。 整張往上或往下偏，到「設定」頁調「上下偏移」。
